# MARGIN · 余白

一个本地优先的中文日记与随笔 Web 应用。打开「此刻」即可开始写作。首页、搜索、回忆和写作统计都使用本机真实记录。

## 启动书房

需要 Node.js 22.12+ 和 npm。首次安装依赖需要网络。

```powershell
npm ci
npm run dev
```

在浏览器打开终端显示的地址。生产预览使用以下命令。

```powershell
npm run build
npm run preview
```

可将 `dist/` 部署到静态站点。哈希路由支持刷新和直接访问文章。HTTPS 或 localhost 下，生产资源首次缓存成功后可以断网重开。日常写作请固定浏览器、域名和端口。开发与预览地址使用各自独立的本地档案。

## 日常使用

| 入口 | 可以做什么 |
| --- | --- |
| 此刻、日记、随笔 | 新建日记或随笔、同日写多篇、回填日期、继续草稿、收藏或标记完稿 |
| 写作 | 编辑标题、段落、列表、引用、链接、照片和说明。进入沉浸模式后继续使用同一编辑器 |
| 文集与标签 | 新建和编辑文集、设置封面、批量归集、重命名或合并标签。删除文集后仍保留文章 |
| 时间档案、日历、回忆 | 按记录日期查看，浏览往年同日或随机旧文。2 月 29 日匹配往年的闰日 |
| 搜索与足迹 | 搜索中英文正文、标题、标签和文集。创作趋势按创建日期计算，当前总字数按现存文档计算 |
| 阅读 | 调整字号、行距和版心，连续滚动或按实际排版分页。用按钮、方向键或手机滑动翻页 |
| 设置 | 配置阅读偏好、减少动效、备份或恢复整库、从回收站移回文章 |

Ctrl/Cmd + S 立即保存，Ctrl/Cmd + B 或 I 设置文字格式，Ctrl/Cmd + K 搜索，Esc 退出沉浸模式。

## 数据流与恢复

React 和 TypeScript 负责界面，Tiptap/ProseMirror 管理富文本文档树。Dexie 在 IndexedDB 中保存文章、照片、版本、标签、文集和偏好。界面通过 liveQuery 接收变化。没有账号、后台同步、第三方分析或正文上传接口。

自动保存防抖为 480 毫秒。编辑器失焦、页面隐藏及离开编辑页时也尝试提交。应用在事务内校验修订号。遇到同一文章的跨标签页冲突，可以另存副本。存储写入失败时可重试或下载当前文字。当前标签页使用 sessionStorage 辅助恢复未提交草稿。

版本历史独立于自动保存。首次保存及相隔五分钟以上的内容变化可建立自动快照，也可以手动留版。恢复历史版本前会先保留当前内容。照片以 Blob 存储，正文引用稳定媒体 ID。单张上限 25 MB，接受 JPEG、PNG、WebP。

在设置里导出 ZIP 可带走所有文章、媒体、版本、标签、文集和偏好。导入时先校验格式、结构、大小和关联，再预览数量。合并遇到同 ID 的不同内容会取消整笔操作。完全替换需要再次确认。单个备份上限为 256 MiB。本地数据库和备份均为明文，清理浏览器数据前请先导出备份。

## PDF

在阅读页导出单篇，在文集页导出整本文集。jsPDF 嵌入本地 Noto Sans SC 字体，生成可选择和复制的中文、英文正文、页码及图片。导出时可指定文件名。随附字体的许可证位于 `public/fonts/OFL.txt`。花卉首页配图为项目原创生成图像。

## 验证

```powershell
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

测试使用隔离的浏览器数据。浏览器截图、下载的测试文件和失败跟踪存入被 Git 忽略的 `test-results/`。已验证的浏览器为 Chromium，视口覆盖 375、390、768、1024 和 1440 像素。Safari、Firefox 和手机输入法需在对应设备上进一步验证。

## 实现边界

日期使用设备本地时区。PDF 使用统一字体重新排版，富文本中的逐字粗斜体和可点击链接未完整映射。照片默认保留原图。设置中可以只对新照片启用压缩。多设备迁移通过 ZIP 完成。首次离线缓存包含约 10 MB 的中文 PDF 字体。
